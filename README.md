# Google-Advanced-Data-Analytics-Certification

The Google Advanced Data Analytics Certificate is a professional-level program designed to develop advanced analytical and data science skills for real-world applications. It focuses on statistical analysis, predictive modeling, machine learning fundamentals, and Python-based data workflows, while emphasizing how to translate complex data into actionable insights. The program combines hands-on labs, case studies, and practice-based assessments created by Google experts, preparing learners for advanced analytics roles that support data-driven decision-making across industries.

I have completed the Google Advanced Data Analytics Certificate, which consists of over 200 hours of instruction and hundreds of practice-based assessments designed to simulate real-world advanced data analytics scenarios. The program’s highly interactive content, developed by Google professionals with decades of experience in data analytics and data science, strengthened my ability to apply advanced analytics tools, platforms, and technical skills required for advanced analytics roles.The program focuses on advanced analytical thinking, statistical methods, machine learning, and data-driven decision-making using industry-standard tools.

This repository documents the course resources (Exampler, Follow-along example, and End-of-course exampler) and my own practical capstone applications learn throughout the program.

📂 Repository Overview

This repository is divided into two parts:

1) Certification Resources - Divided into 4 courses, each of which contains its own example, follow-along notation, and end-of-course project
  
2) Capstone Application - My own personal project where I apply my understanding and skills to the SECOM dataset

📌 Executive Summary

This project addresses a critical challenge in semiconductor fabrication: identifying faulty wafers early in the production line. Using a high-dimensional dataset of 590+ sensor readings, I developed a machine learning pipeline that predicts "FAIL" states with a focus on maximizing Recall, thereby reducing the operational costs associated with downstream processing of defective units.

In the SECOM Capstone Application Project, a Jupyter Notebook on Google Colab was used, and below is the model deployment pipeline:

  1)Data import
  2)Preprocessing and Cleaning  
  3)Feature Selection (VarianceThreshold, Hypothesis testing with ANOVA)  
  4)Feature Scaling (StandardScaler)  
  5)Model Building  
  6)Logistic Regression (Imbalanced sampling, Oversampling, Oversampling with SMOTE)
  7)Random Forest Model (Oversampling with SMOTE, GridSearchCV)  
  8)XGBoost Model 
  9)Model Evaluation (Accuracy, Precision, Recall, F1-Score)
